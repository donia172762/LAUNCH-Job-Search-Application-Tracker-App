LAUNCH — Job Search & Application Tracker App
LAUNCH is a premium mobile UI/UX project that helps job seekers discover opportunities, save jobs, and follow their applications in one place.
Project Overview
- Project type: Final UI/UX design project
- Platform: Mobile app — iPhone 16 Pro Max
- Frame size: 440 × 956 px
- Design tool: Figma
- Deliverable: Interface designs, reusable components, supporting states, and an interactive prototype

Main Screens
Screen	Purpose
Discover Jobs	Browse available opportunities and open job cards.
Job Details	Review the role, requirements, and job information.
Login / Sign Up	Access features that require an account.
Saved Jobs	View saved opportunities.
Application Tracker	Follow application progress.
Application Details	Review an individual application and its status.
Profile	View account and profile information.
Search Results	Explore jobs matching a search.


Core User Flows
1. Browse as a guest: Discover Jobs → Job Details.
2. Save a job: Save action → Login / Sign Up when required → return to the intended action.
3. Track applications: Application Tracker → Application Details, with authentication required for guests.
4. Search: Search entry → Search Results → Job Details.
Users can browse jobs without an account. Saving jobs and tracking applications require signing in.

Brief Case Study
Problem
Job seekers need a clear way to discover opportunities and keep track of jobs and applications without losing context between screens.
Goal
Create a cohesive mobile experience that makes browsing accessible to guests and connects saved jobs and application tracking to an account.
Design Approach
Build on the existing Discover Jobs screen, establish reusable components, and apply consistent typography, colors, and navigation across the remaining screens. Include supporting states and prototype connections to demonstrate the key journeys.
Outcome
A connected UI/UX concept for job discovery, saved opportunities, and application tracking, presented through a Figma prototype.
Content and Scope
- Job information is fictional and used for demonstration.
- Images and company logos remain placeholders for later replacement.
- This is a design prototype; authentication, search, saving, and application tracking represent interface flows rather than a deployed backend.
- No installation or code setup is required to review the project.
